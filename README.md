# د. مروى ثابت · Dr. Marwa Thabet

Website prototype for Dr. Marwa Thabet, clinical nutritionist: public site (Arabic-first, English toggle), client portal and nutritionist dashboard with a client-file form.

- Static site, no build step: `index.html` + `img/`.
- Contact details live in the `CONFIG` block at the top of the script in `index.html`.
- This is a front-end prototype: client files are kept only in the browser (localStorage), not on a server.
